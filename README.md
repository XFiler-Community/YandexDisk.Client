# Yandex Disk API Client for .NET

[Yandex Disk Rest API](https://tech.yandex.ru/disk/rest/) client library for .NET

[![Nuget](https://img.shields.io/nuget/v/XFiler.YandexDisk.Client?label=XFiler.YandexDisk.Client)](https://www.nuget.org/packages/XFiler.YandexDisk.Client)

This is a fork [of this library](https://github.com/raidenyn/yandexdisk.client), optimized for Native AOT publishing.

Previously published as [`Egorozh.YandexDisk.Client`](https://www.nuget.org/packages/Egorozh.YandexDisk.Client)
from [egorozh/YandexDisk.Client.Net](https://github.com/egorozh/YandexDisk.Client.Net).
Starting with 9.0.0 the package is `XFiler.YandexDisk.Client` and the namespace is `XFiler.YandexDisk.Client`.
